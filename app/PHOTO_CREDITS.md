# Room-image credits

All eighteen room images in assets/hotel-11.jpg to assets/hotel-36.jpg were generated with OpenAI image generation on 18 November 2026 for this coursework prototype. Each hotel has one different main image. Two previously approved generated samples were retained; sixteen new rooms were generated individually. 

The images are photorealistic generated illustrations, not actual hotel photographs, property evidence or reliable indicators of a real location, rating, amenity or price. Relative visual tiers are design choices for fictional records, not real hotel classifications or market estimates.

Images are stored locally as web JPEGs. Only file-format/quality encoding was applied; framing, colours and dimensions were preserved. Original generated PNGs remain in the execution workspace. See ../docs/IMAGE_CATALOG.json for the one-to-one image mapping and source/file hashes. Source generation briefs are retained in the development workspace.
